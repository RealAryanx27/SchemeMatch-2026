# SchemeMatch-2026
Next-Generation Public Welfare Execution Engine built for **AVINYA 2K26 (SIIC, IIT Kanpur) — Problem Statement 07**.

## Core Features
- **Deterministic Match Engine:** 0% hallucination rule filtering with explainable match reasons and missing information identification.
- **Pre-Rejection Shield:** Multimodal Vision OCR that catches document discrepancies prior to official submission.
- **Welfare Basket:** Intelligent scheme stacking to maximize total citizen benefit coverage.
- **Multilingual Voice Intake:** Natural language profile extraction for non-literate citizens.

## Setup
1. Clone repo: `git clone https://github.com/RealAryanx27/SchemeMatch-2026.git`
2. Create venv: `python -m venv venv`
3. Activate venv: `venv\Scripts\activate` (Windows)
4. Install dependencies: `pip install -r requirements.txt`
5. Run App: `streamlit run app.py`
